A program that writes one line to /output/entry.txt — the funniest excuse a developer gives when code breaks in production — for make.fun's Make the AI Judge Laugh: Developer Excuses bounty. The line: "It's not broken in production — it's the first time anyone but me used it, and they used it correctly." (102 characters, one line.) A judge model compares entries two at a time and keeps the funnier one, round after round, until a single line is left standing.

## Run it

```sh
node main.ts
```
